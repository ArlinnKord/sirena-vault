# Коды и статусы

Сводный словарь. Подтверждённое практикой — помечено. Непроверенное — сверять с памятками а/к.

## Статусы сегментов (рейсов в PNR)
- `НК` — бронирование подтверждено
- `UN` — рейс отменён а/к (цифра после кода = число пассажиров: УН2 — для двоих)
- `TK` — изменения в расписании (schedule change)
- `ХХ` — места сняты (возврат места на участке; цифра = число пассажиров)

## Статусы купонов электронного билета
- `O` Open — открыт · `A` Airport Control · `C` Checked-in · `L` Lifted/Boarded · `F` Flown/Used (выполнен)
- `P` Printed · `E` Exchanged/Reissued · `G` FIM · `R` Refunded · `V` Void · `T` Paper
- `S` Suspend · `U` Unavailable (только обмен) · `I` Irregular · `N` Coupon Notification · `Z` Closed (закрыт)

Возвращаются/обмениваются только **O**; `C` — сначала снять с рейса; `F` — не возвращается.

## Категории пассажиров
Возрастная шкала: **0–2 = младенец · 2–12 = ребёнок · 12+ = взрослый** (09.09.2026).
- `ААТ` — взрослый (12+)
- `РБГ` — ребёнок 2–12 в сопровождении взрослого (подтверждено 09.09; совпадает с `КИ/КПА/РЕБЕНОК`)
- `АГА` — ребёнок без сопровождения (напр. выписка ребёнка от 2 до 12 без взрослого: `…*АГА`)
- `РВГ` — младенец 0–2 (без места, на руках) · `РМГ` — младенец 0–2 С местом (в т.ч. Аэрофлот: младенца с местом оформлять категорией РМГ, НЕ рвг)
- Спецкатегории граждан (военные и пр.) группа НЕ обрабатывает — «можно не париться»

## Блоки PNR
- **Блок 3** — два типа записей:
  - **SSR** (рус. ССР) = ремарки/запросы: спецпитание, коляска, [[Коды и статусы#FOID|FOID]]… Формат `3С1П1<код>` (`3С1П1ВГПЩ`)
  - **СВС** (SVS) = доп. услуги: место, багаж. Нумеруются У1/У2 → тарификация `ТМ/<буква>+Уn` → ЕМД
- Блок 5 — примечания (аналог OSI) · Блок 9 — контакты
- Удаление строки: `<блок><номер>"` — `3У1"` (услуга), `51"` (примечание), `91"` (контакт)

### FOID
SSR-ремарка с документом пассажира; вносится автоматически при добавлении пассажира в блок SSR. Новинка: раньше была только в Amadeus, теперь и в Сирене.

### SSR-коды из реальных броней (примеры)
- `INFT` — infant, связка «младенец»: создаётся автоматически, когда в брони есть младенец без места.
- `BSCT` — bassinet: запрос детской люльки на борт для младенца.
- `ADMD` — запрос доп. места багажа (напр. 23 кг): строка-условие вида `ADMD … HK1 TO <АК> BY <дата> OTHERWISE WILL BE CANCELLED` — запрос у а/к с тайм-лимитом (пока НЕ оформлено как ЕМД).
- `ПРОЧ` — общая ремарка (в примере — о реаккомодации: `REACC FROM … DELAY`).

### SSR-коды из графического редактора А4 (Азимут) — 09.09.2026
Официальные расшифровки а/к А4. ⚠️ Один код у разных а/к может значить разное (см. PETC) — сверять с перевозчиком.
- Животные: `PETC` — собака-поводырь · `PETD` — животное в салоне до 8 кг, более 10 суток до вылета (все сегм.) · `AVIH` — животное в багажном отделении, более 3 часов
- Кресла-каталки: `WCHR` — кресло-каталка (рампа) · `WCHS` — кресло-каталка (к трапу/месту) · `WCHC` — кресло-каталка (место в салоне) · `WCMP` — кресло-каталка (с ручным приводом)
- Особые пассажиры: `BLND` — слепой · `DEAF` — глухой · `VIP` — VIP-пассажир
- Багаж/грузы: `WEAP` — оружие и военная аммуниция как проверяемый багаж · `CBBG` — багаж в кабину · `XBAL` — 1-е место 23кг 203см для LT-субсидированных тарифов, более 3 часов · `POST` — коммерческая корреспонденция
- Служебные: `NOTE` — комментарий в DCS · `OTHS` — требует действия/инфо по брони, для которой нет кода SSR (ответ не обязателен) · `EXCH` — EXCLUDE*FROM*CHARGEABLE (исключить из оплачиваемого)

> [!warning] PETC — трактовка различается
> У А4 `PETC` = собака-поводырь. В примерах с пульта Сирены `3УАС1П1PETC CAT 8КГ` — PETC использован как «животное в салоне» со свободным описанием. Смотреть контекст строки и правила перевозчика.

> [!note] Урок
> Такие коды НЕ всегда есть в списках IATA/памяток — расшифровывать по контексту и свободному тексту SSR-строки или по документации конкретной а/к.

## Питание (международные коды SSR)
VGML (вегетарианское), VLML, KSML (кошер), MOML, CHML (детское), DBML, HNML (индуистское), WCHR (коляска), UM (ребёнок без сопровождения)

## Бренды тарифов
- Аэрофлот: эконом NB/EC/EL (+FT/ER), премиум CA/CC/CL, бизнес BA/BC/BL. У других а/к коды пересекаются (OP, EL у B2) — смотреть по перевозчику.
- «Тариф» (бренд) НЕ строго привязан к подклассу: буква может остаться, продукт меняется (light → premium с багажом); выбор — параметром `ПТ:БРЕНД=…`.
- Жёсткое правило PNR: подкласс и бренд у ВСЕХ пассажиров одной брони одинаковые. Хотят разное — разные брони (сплит `Д1`). Различия тарифов внутри брони — по категории пассажира (ААТ/РБГ/младенец), не по бренду.

## Код тарифа в распечатке билета (fare basis)
Полный код тарифа брони = `<буква подкласса><бренд><OW|RT>` (разобрано 10.09.2026):
- `FLTOW` = **F** (подкласс бронирования) + **LT** (Light) + **OW** (one way)
- `NECOW` = **N** (подкласс) + **EC** + **OW**
- в другом билете на конце было `…RT` = round trip
В билете таких кодов два — по направлению.

> [!warning] `EC` у U6 не подтверждён
> Не путать с Аэрофлотом, где `EC` = classic. Смотреть по перевозчику.

Смежные сокращения шапки билета (уточнено 10.09.2026): `АГН-<код>` — агентство · `ПУЛ-…` — пульт · `ППР-<номер>` — **пункт продажи** · `ГРД-МОВ` — пара пунктов шапки · `U6 <код>` — внутренний код брони у а/к (параллельно PNR агентства). `ОП-…` и `ИНД.ОЦ` — по практике «неважно» (можно не расшифровывать). Остальные нерасшифрованные (`ОИД`, `АЗ/ЗАПР`, `НДСА`, `КО.00`, `СБ-1Н`, `ГРД`, `СБ-15`) — уточнить на пульте.

## Багаж — единицы измерения (в выводах ТМ/Б)
КМ — кол-во мест · KG — кг · LB — фунты · LCM — сумма измерений см · LI — сумма измерений дюймы

## Символы карты мест (КМС) — разобрано 10.09.2026
Свободно/занято: `X` / `Х` — свободно · `*` — занято.

Признаки места:
- `А` не для младенца · `Б` не для инвалида · `У` не для несопровождаемого ребёнка · `Р` не для детей · `М` младенец · `Ю` несопровождаемый ребёнок · `Ж` животные · `И` для инвалида
- `О` у окна · `=` проход · `Н` место для ног · `С` тихое · `Й` лицом к хвосту · `Д` неоткидывающаяся спинка · `Л` полка
- `Э` эконом-комфорт · `В` верхний салон · `Ф` перед кабиной экипажа (перегородка) · `<` крыло под местом · `К` у кухни · `Т` у туалета · `!` перегородка · `Е` доп. выход
- `П` место выдаётся при регистрации · `$` платное · `?` льготное · `@` — в источнике противоречие: в шапке «свободное место», ниже «расширенные характеристики». Уточнить на пульте.

> [!info] Только свой салон
> `КМС1` показывает лишь ту часть ВС, где есть места забронированного подкласса: эконом-бронь → бизнес-салона на карте не будет. См. [[Оформление места в салоне (пример)]].

## Коды документов (картотека «ДОК»)
`ПС` (паспорт РФ) · `ПСП` (загран РФ) · `СР` (свидетельство о рождении) · `НП` (нац. паспорт иностранца; для РФ запрещён) · `ДП` (дипломатический) · `СП` (служебный) · `ВЖ` (вид на жительство) · `УД` (удостоверение). Полный разбор и команда смены `ДД` — [[Замена документов — коды и команды]].

## Прочее
- `NUC` — валюта систем бронирования (нейтральная единица расчёта)
- OW — one way (в одну сторону) · RT — round trip (туда-обратно) · NS — no-show
