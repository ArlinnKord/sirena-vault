# Команды пульта

Базовые команды Сирены. По операциям — в папках [[Сирена — навигация|навигации]].

## Вход / выход
- Вход: `ТКП26МКВ0013/ПАРОЛЬ` (код кассира/агентства/пароль).
- Выход: `.` (точка).

## КИ — кодирование / декодирование
КИ = транслитерация (название → код) + расшифровка (код → название).
- По названию: `КИ/<квалификатор>/<название>` — `КИ/СФЕ/УФА`
- По коду: `КИ/<квалификатор>//<код>` — `КИ/АВК//DP` (двойной слэш обязателен!)
- Без квалификатора: `КИ/КРАСНОЯРСК`

Квалификаторы: СФЕ город, АЭР аэропорт, АВК авиакомпания, АГН агентство, ГОС страна, ТТС тип самолёта, ДОК документ, КВА валюта, КПА категория пассажира, ФОП форма оплаты, ССР код услуги, СБР сбор, РЕГ регистрация.

## Справки
- `?<команда>` — справка по команде (коды операций внутри ТМ не объясняет!)
- `ИА/<а/к>` — интерфейс а/к: документы, правила, услуги (`ИА/WZ`)

## Корректировка данных (смена ФИО/паспорта в выписанном билете)
- `ТП1/16` — правила тарифа по категории 16 УПТ (разрешена ли смена данных и сбор)
- `ТМ/БЛД1` — расчёт/счёт за корректировку; `БЛД1` — исполнение после оплаты; `БЛРД1` — ручная маска
- `-1"…` — ФИО/дата рождения/пол; `ДД1/…` — паспорт/документ (паспорт через `-1` НЕ менять)
- Скелет и путь через УСЛТ+ЕМД — [[Корректировка данных — команды]]

## Расписание
- `ССПТСОЧ` — расписание по паре городов; `ССПТСОЧ1911-ЮТ` — с датой и а/к
- `СМОВ` — города из пункта; `ОБ2211` — обратные рейсы
- `F6/F5` — листание по датам
- `ВМ,МОВ` — минимальное стыковочное время

## Наличие мест
- `1<ГГ><ГГ><ДДММ>[-АК]` — `1МОВТЮМ2511*Э`, `1ОШШДМД0409-ТФ`, `1ШРМПЛК1010-SU`, `1СПТТЮМ2507-ЮТ#МОВ` (пересадка)
- `1МОВТЮМ2511*Э` — с запросом кода бронирования
- `#N` — инфо по рейсу; `1*` — назад к экрану наличия
- Коды: МОВ/ШРМ/ВНК/ДМД/ПЛК (Москва/СПб: СПТ), ОШШ, ЕКБ, МРВ, ТБС, ТЮМ

## Бронирование с экрана
- `0<строка><класс><мест>` — `02Э1`; стыковка разными классами слитно: `04ЭП1`, `01UQ1` (см. [[Создание брони на примере. (стыковка, разные подклассы)]])
- **`0ПРИБ/<N>` — ПАССИВНЫЙ СЕГМЕНТ в позицию N. При ОБМЕНЕ добавляется ВСЕГДА** (подтверждено на пульте 10.09.2026): Сирена не понимает действие между двумя рейсами, у которых пункты вылета и прилёта совпадают (напр. ЕКБ→ЕКБ), и НЕ ДАЁТ СОХРАНИТЬ. Добавляется НЕ при бронировании нового рейса, а **непосредственно перед самим обменом**. Порядок: новый рейс бронируем строкой ВЫШЕ старого (нижняя/старая строка механически меняется на верхнюю/новую) → `Х<N>` → `ЕО` → перед обменом `0ПРИБ/N` → `ЕО` → `ПО*N`. В новой брони `0ПРИБ/2` — чтобы рейсы шли по порядку (в Инструкции назван «сегмент прибытия»).

## ОЦ — оценка маршрута (варианты перелёта)
- `ОЦМОВСПТ2511-ПЛ` — варианты; `ОЦ*` — из активного PNR; `ОЦ#N` — с экрана наличия
- `#N` — уточнить вариант; `01` — бронировать по 1-му варианту; `0` — бронировать после уточнения

### `ОЦ#N` — как узнать цену подкласса (10.09.2026, практика обменов)
- На экране наличия нового рейса `ОЦ#<N>` (N = номер строки рейса) = **выбор рейса** → открывается **список подклассов с ценами**; по нему выбирают, какой подкласс взять.
- Итоговую доплату при обмене даёт НЕ `ОЦ`, а расчёт в брони: `ТМР/ПО*N`.
- Точечно по подклассу — тарифная справка `Т<ГГ><ГГ><даты>-<АК>*<подкласс>` (буква команды — одна **`Т`**, сразу за ней слитно коды городов; напр. `…*O`), параметр `/КБ=<подкласс>`.

> [!info] Два окна пульта
> Работа удобнее в двух окнах: в одном — наличие/`ОЦ#1` (выбор рейса и подкласса с ценой), во втором — оценка рейса и, если цену забыли, тарификация текущей брони (`ТМ`/`ТМР/ПО*N`).

## Билет / ЕМД — открытие
- `ЭБ<N>*<M>` — билет пассажира N, сегмент M из брони (сегмент всегда!)
- `ЭБ#<номер>` — прямой поиск (у Аэрофлота билеты «заблокированы» в GUI — только так)
- `*ЭМД` — список ЕМД брони; `ЭБК/почта` — МК на почту; `ЭМДК#N` — квитанция ЕМД

## Валюты / конвертация
- `ПВ/<сумма>/<из>/<в>[/дата]` — перевод суммы: `ПВ/120/ЕВР/РУБ` (120 EUR → RUB), `ПВ/500/РУБ/ДОЛ`
- `NUC` — универсальная валюта (между а/к): `NUC × ROE` = сумма в **ЕВРО**, затем ЕВРО → рубли через `ПВ`. Разбор строки `РАСЧ ТАР` — [[Аэрофлот — рерутинг]]

## Сохранение
`Е`/`ЕО` — сохранить; `И`/`ИО` — не сохранять. Подробно: [[Сохранение Е-ЕО-И-ИО]].
