# Таксы по сегментам — запрос ИС

Подробная информация о **таксах (сборах) по сегментам** (пример — Аэрофлот). Записано 30.09.2026, на пульте не проверялось.

## Алгоритм
1. `ЭБ#<номер>` — открыть билет (у Аэрофлота в GUI билет «заблокирован», только так).
2. В **нижней строке** билета — разбивка цены по тарифу **по сегментам**.
3. Скопировать билет целиком.
4. Вставить в **нашу таблицу такс**, вкладка **ТКП** — там есть готовая команда «ТАКСЫ ПО СЕГМЕНТАМ (запрос `ИС`)».
5. Выполнить `ИС` **по каждому плечу** — на каждый сегмент своя строка.

## Формат
```
ИС<пункт вылета><пункт прилёта><ДДММГГ вылета><ДДММГГ оформления>-<АК>*<категория пассажира>
```

Две даты обязательны: **дата вылета** и **дата оформления**. Звёздочка перед категорией обязательна.

Примеры (SU, взрослый):
```
ИСУЛКШРМ280926260926-SU*AAA
ИСШРММУН290926260926-SU*AAA
```
- `УЛК` (Ульяновск) → `ШРМ` (Шереметьево), вылет 28.09.26, оформление 26.09.26
- `ШРМ` → `МУН` (Мюнхен), вылет 29.09.26, оформление 26.09.26
- `SU` — авиакомпания, `AAA` — категория пассажира (взрослый)

> [!warning] Не путать с другими ИС/УС
> `ИСМОВСПТ-ПЛ` — справка всех сборов на паре городов (без дат).
> `ИС*N` — условия применения сборов из строки N после справки `ИС`.
> `УС*N` — условия применения сборов для сегмента N (вторичный запрос после `ТМ`).
