# Возврат билета — команды

Быстрый скелет. Развёрнуто — [[Добровольный возврат]] и [[Вынужденный возврат]] (каждая команда там расписана с подсказками и граблями).

## Скелет (общий для всех возвратов)
1. `*<номер брони>` — открыть бронь (ШАГ 0) → `*Р`
2. `*С` + `ЭБ#<номер>` — статусы купонов (возвращаются только **O**)
3. `*ЭМД` — доп. услуги: выпущенные → расчёт `ТМ/АП+Уn` (сумма со знаком минус) → возврат `ЭМДВ#N` (добр.) / `ЭМДВВ#N` (вынужд.); забронированные, но не выпущенные → `3У<N>"`
4. `ТМ/П` → `ТП1/16` — правила возврата по УПТ
5. `ТМР/АП…` — авторасчёт суммы (сверять с правилами!)
6. Возврат → листать стрелками (→) до конца → подтверждение
7. `ЭМД/ПШ` — квитанция сборов/штрафа (если есть)
8. `ХМ` / `ХХ1` — снять места → `ЕО` (запись не нужна → `И`)

## Коды возврата — развилка
| Ситуация | Код |
|---|---|
| Автоматический расчёт (система сама решает добр./вынужд.) | `АП` |
| Добровольный возврат (клиент передумал, штраф) | `АПД` |
| Вынужденный (по вине а/к: отмена/задержка) | `АПВ` |
| Экстренный (аннулирование) | `ОТ` |
| Конкретному пассажиру | `АП<N>` (напр. `АП2`) |
| По сегменту N (живой рейс при отменённом в PNR) | `АПВ*N` |
| Через маску / ручная маска (отказ автоматики) | `АПР` / `АПРД` |

> [!warning] Частые грабли
> - Авторасчёт может посчитать штраф там, где по правилам его нет — сверять с `ТМ/П`.
> - В PNR остался отменённый рейс (UN) → расчёт «на всё» падает: считай по живому сегменту `ТМР/АПВ*N`.
> - Войд (аннуляция в день продажи) — отдельная процедура, см. ниже.
> - Аэрофлот: билет открывать через `ЭБ#` (в GUI «заблокирован»).

## Войд (аннуляция выписки в день продажи)
`ЭМДВВ#` (вернуть ЕМД) → `ОТ/-` (возврат с сохранением места) → `ЕО` → `АМ/-` (сброс тарификации) → `ЕО` → `ХМ` (снять маршрут).

## Порядок Миксвел (МКЛ) — сверка 21.09.2026

> [!info] Источник
> Инструкция кассира ГРС «Миксвел», ч. 2, гл. 5 «Возврат билетов (запрос `АП`)», с. 66–90 (версия 05.06.26). Миксвел — **другая ГРС** (центр `МКЛ`), язык команд совпадает с Сиреной. Сверка с нашими записями: [[Миксвел — расхождения с Сиреной и новые команды]].
> ⚠️ **На нашем пульте не проверялось.** Ниже — порядок МКЛ как он написан; что из этого совпадает с Сиреной, а что специфика МКЛ — неизвестно.

1. `ТМ/П` → `ТП(ВАР)` / `ТП(N)/16` или `/33` — прочитать УПТ (в инструкции это прямое требование **до** процедуры)
2. `*<номер брони>` — вызвать PNR
3. `ЭБ#<номер>` — статус купона
4. **Заранее** установить активные бланки: `СМ/ЭМД` (МСО), `СК/EMD` (квитанция агентских плат) — после подачи `АП` установить их уже нельзя
5. `АП<Р><Вид><О><ПАСС><*СЕГМ></->` → предупреждение об активных бланках → листание ВПЕРЁД
6. Не устраивает оценка → листание «ВПЕРЁД ПО ДАТЕ» → маска (поля правятся вручную, ответственность на кассире); `ИО` отменяет операцию
7. **`ЕО` — обязательно, и только потом ЭМД**
8. `ЭМД/ПШ/АП` (сбор перевозчика — обязательно, иначе не попадёт в финансовый отчёт) · `ЭМД/ПК` (плата агентства) · `ЭМД/СП/АП` (справка о возврате) · `ЭМД/СП/ИСП` (справка об использовании участков)
9. `Е` — конец диалога

> [!warning] Расхождения с нашим скелетом
> - **Места.** В МКЛ «операция возврат билетов включает возврат мест, подсчёт суммы, печать ЭМД» → возврат мест делает сам `АП`. У нас места снимаются отдельным шагом (`ХМ`/`ХХ1`). Либо шаг лишний, либо это разница систем — проверять на пульте.
> - **Обозначение мест.** В МКЛ `ХХ` = возврат места (`ХХ2` — по сегменту 2), и есть отдельная гл. 5.8 «возврат только мест без финансового расчёта». У нас `ХМ` (маршрут) / `ХХ1` (участок).
> - **`АП(ПАСС)*(СЕГМ)/-`** — в МКЛ это возврат билета **без сдачи мест** (места сдаются потом отдельно), то есть в МКЛ наоборот: по умолчанию места сдаются, `/-` — исключение.
> - **`АПР`.** МКЛ прямо запрещает взимание сборов а/к при ручном возврате: «НЕВОЗМОЖНО ВЗЯТЬ СБОР ПРИ ВОЗВРАТЕ». У нас в [[Добровольный возврат]] записано обратное («в `АПРД` вписать сборы а/к и валюту») — ⚠️ **прямое противоречие, проверить**.
> - **`АП` без `Вид`.** В МКЛ система смотрит признак рейда: есть признак вынужденного возврата → считает как вынужденный.
> - **Игнорирование после `АП`.** В МКЛ запрос `И` отменяет возврат и **замораживает места**.

**Чего в нашем скелете нет вообще:** `3С(СЕГМ)ПРОЧРВВП(свободный текст)` — разрешить вынужденный возврат, когда по УПТ он запрещён; псевдовозврат `АПВ/-` (сегмент из PNR не удаляется); «СЭБ <АК> ТРЕБУЕТ ОТДЕЛЬНОЙ ОПЕРАЦИИ НАД КАЖДЫМ ИЗ БИЛЕТОВ» → `АП1`, `АП2`; возврат начинать с **ребёнка без места** (иначе «ОШИБКА: НА СДАВАЕМОМ СЕГМЕНТЕ ОСТАЮТСЯ БИЛЕТЫ»); перерасчёт использованных участков маршрутного тарифа и «туда-обратно» считается **вручную**; форма оплаты сбора = форма оплаты билета, доп. агентские платы — за НАЛ, кроме ПК+авторизация.
