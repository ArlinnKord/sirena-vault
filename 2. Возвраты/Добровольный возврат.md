# Добровольный возврат (клиент передумал)

Код: **АПД** — добровольный возврат (со штрафом по правилам тарифа). `АП` — авторасчёт: сам выбирает добровольный/вынужденный по факту изменений; если изменений не было — результат как у АПД. ⚠️ АПД vs АП для добровольного возврата — «дело привычки» (09.09.2026): для добровольного делают просто `АП`; `АПВ` — только для вынужденного.

Быстрый скелет: [[Возврат билета — команды]].

## Порядок
0) `*<номер брони>` — открыть бронь (ШАГ 0, в конспектах часто опускают). Полезно `*Р` — сегменты/пассажиры.
1) Статусы купонов: `*С` (сводка по PNR) и `ЭБ#<номер>` (в билете, по участкам). Возвращаются ТОЛЬКО неиспользованные купоны:
   - **O** (open) — ок, возвращаем;
   - **C** (checked-in) — зарегистрирован на рейс → сначала снятие с рейса;
   - **F** (flown) — использован, не возвращается.
2) Правила тарифа: `ТМ/П` → `ТП1/16` — посмотреть штраф за возврат и условия (УПТ, кат. 16).
3) Проверка доп. услуг (ОБЯЗАТЕЛЬНО до возврата билета):
   - `*ЭМД` — список выпущенных ЕМД; выпущенные → вернуть `ЭМДВ#<N>` (добровольный) / `ЭМДВВ#<N>` (вынужденный);
   - услуги только забронированные (СВС-строки У1/У2 в PNR, ЕМД не выпускали) → снять строку `3У<N>"`, место — `34"`, ничего не выпуская.
   Порядок: ЕМД → билет → места → `ЕО`.
4) Сумма к возврату: `ТМР/АПД` — предварительный расчёт. ⚠️ Авторасчёт НЕ панацея: всегда сверять с `ТМ/П`/`ТП01/16` (реальный случай: авто взял штраф ~3000 ₽, по УПТ возврат был без штрафа).
5) Возврат:
   - `АП` / `АПД` — всем пассажирам PNR сразу;
   - `АПД<N>` — конкретному пассажиру (напр. `АПД2`);
   - маска `АПР`; ручная маска `АПРД` (если автоматика отказывает — в поля вписать сборы а/к и валюту).
   После операции — **ЛИСТАТЬ СТРАНИЦЫ СТРЕЛКАМИ ВПРАВО до конца** → финальный экран «после этого действие будет невозможно отменить» → подтверждение. (Общий шаг всех возвратов АП/АПД/АПВ, не только АПВ — подтверждено 09.09.2026; легко пропустить.)
6) Сборы за возврат (квитанция/штраф): `ЭМД/ПШ`.
7) Снять места: `ХМ` (весь маршрут) или `ХХ1` по участкам (до вылета, чтобы не было no-show) → `ЕО`. Запись не нужна → `И`.

## Памятка
- «Передумал» = добровольный → штраф по УПТ кат. 16.
- Автовыбор `ТМР/АП` vs принудительный `ТМР/АПД`: при отсутствии вынуждающих обстоятельств совпадают; различие видно при отмене/задержке рейса (тогда корректнее АПВ).
- Возврат по конкретному пассажиру без сплита: `АПД<N>`.

## Порядок Миксвел (МКЛ) — сверка 21.09.2026

> [!info] Источник
> Инструкция кассира ГРС «Миксвел», ч. 2, гл. 5 «Возврат билетов (запрос `АП`)», с. 66–90, включая 5.1 (возврат при использовании ЭМД), 5.2 (примеры), 5.6–5.9 (версия 05.06.26). Общая карта соответствий — [[Миксвел — расхождения с Сиреной и новые команды]].
> ⚠️ **На нашем пульте не проверялось.** Это порядок МКЛ как он написан в инструкции; где МКЛ совпадает с Сиреной, а где расходится — по нашим записям определить нельзя.

**Прямой порядок из инструкции МКЛ:**

1. `ТМ/П` → `ТП(ВАР)` / `ТП(N)/16` или `/33` — прочитать УПТ. В инструкции это отдельное требование **до** процедуры, с оговоркой: «Для более точного получения условий применения тарифа после продажи использовать `ТМ/П` и далее `ТП(ВАР)`».
2. `*<Номер_PNR>` — вызвать PNR.
3. `ЭБ#<номер>` — проверить статус купона.
4. **Установить активные бланки заранее:** `СМ/ЭМД` (МСО) и `СК/EMD` (квитанция агентских плат). Прямая оговорка: «После подачи запроса `АП` выдаётся предупредительное сообщение, в котором указывается, какие активные бланки установлены… Если электронные ЭМД не установлены, то установить их в процессе возврата нельзя».
5. `АП<Р><Вид><О><ПАСС><*СЕГМ></->` → реплика «ВЫБРАНЫ БЛАНКИ…» → листание ВПЕРЁД.
   - `Вид`: `В` вынужденный / `Д` добровольный. **Без вида** система проверяет признак рейда: есть признак вынужденного → считает по правилам вынужденного, иначе добровольного.
   - `Р` — ручной возврат с использованием маски; `О` — оформление МСО вручную; `ПАСС` и `СЕГМ` взаимоисключают друг друга.
   - Возврат только всех неиспользованных участков; указан использованный сегмент → «НЕВОЗМОЖНО СДАТЬ/ОБМЕНЯТЬ 'ИСПОЛЬЗОВАННЫЙ' СЕГМЕНТ».
6. Оценка не устраивает → листание «ВПЕРЁД ПО ДАТЕ» → маска в режиме ВВОД, поля правятся вручную (ответственность на кассире) → снова предварительная справка. Отменить операцию — `ИО`.
7. **`ЕО` — обязательно, и только потом печать ЭМД.**
8. `ЭМД/ПШ/АП` — ЭМД на сбор перевозчика при отказе (**обязательно, иначе не отразится в финансовом отчёте**); `ЭМД/ПК` — плата агентства; `ЭМД/СП/АП` — справка о возврате; `ЭМД/СП/ИСП` — справка об использовании участков. По каждому взимаемому сбору — отдельный ЭМД, на каждого пассажира — отдельный ЭМД.
9. `Е` — завершить диалог (так в примере 5.6: `АПВ` → `Е`).

> [!warning] Расхождения с нашим порядком
> | | МКЛ | У нас |
> |---|---|---|
> | Снятие мест | входит в операцию `АП` автоматически | отдельный шаг `ХМ` / `ХХ1` (шаг 7) |
> | Маска мест | `ХХ` = возврат места, `ХХ2` — по сегменту | `ХМ` (весь маршрут), `ХХ1` (участок) |
> | `АП(ПАСС)*(СЕГМ)/-` | возврат билета **без** сдачи мест | не описано |
> | Активные бланки | обязательны **до** `АП` (`СМ/ЭМД`, `СК/EMD`) | не описано |
> | ЭМД после возврата | обязательно `ЭМД/ПШ/АП` | `ЭМД/ПШ` |
> | `АП` без вида | смотрит признак рейда | «авторасчёт сам решает» |
> | `АПР` | запрет взимания сборов а/к — «НЕВОЗМОЖНО ВЗЯТЬ СБОР ПРИ ВОЗВРАТЕ» | «в `АПРД` вписать сборы а/к и валюту» ⚠️ **прямое противоречие** |
> | Игнорирование после `АП` | отменяет возврат и **замораживает места** | мягче («места не будут возвращены») |
>
> По п. 1 (места) и п. 7 (АПР) вывод сделать по нашим записям нельзя — нужна проверка на пульте.

**Чего в нашем порядке нет:**

- `3С(СЕГМ)ПРОЧРВВП(свободный текст)` — разрешить вынужденный возврат, если по УПТ он запрещён («Если по УПТ запрещён вынужденный возврат, то, введя поле спецобслуживание с кодом ПРОЧ и подкодом РВВП на основании документа…»);
- псевдовозврат `АПВ/-` — сегмент из PNR не удаляется;
- «СЭБ <АК> ТРЕБУЕТ ОТДЕЛЬНОЙ ОПЕРАЦИИ НАД КАЖДЫМ ИЗ БИЛЕТОВ» → возврат по каждому билету отдельно (`АП1`, `АП2`);
- при возврате неполному составу — начинать с **ребёнка без места**, иначе «ОШИБКА: НА СДАВАЕМОМ СЕГМЕНТЕ ОСТАЮТСЯ БИЛЕТЫ»;
- перерасчёт использованных участков маршрутного тарифа и «туда-обратно» делается **вручную**;
- форма оплаты сбора = форма оплаты билета; доп. агентские платы взимаются за НАЛ, кроме ПК+авторизация;
- возврат денег по ЭБ — только в пунктах продажи **оформляющего** агентства;
- реплика «СЛОЖНЫЕ УСЛОВИЯ. ИСПОЛЬЗУЙТЕ ЗАПРОС `АПР` ИЛИ `ПОР`» — сигнал переходить на ручной возврат;
- запрещена операция `АПР` на сегменты прибытия.
