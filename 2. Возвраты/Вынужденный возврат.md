# Вынужденный возврат (по инициативе а/к: отмена/задержка рейса)

Код: **АПВ** — вынужденный возврат. Возврат по правилам без штрафа (или с возвратом невозвратного — по УПТ и основаниям).

Быстрый скелет: [[Возврат билета — команды]]. Кейсы: [[U6 — отмена рейса]] · [[Аэрофлот — возвраты (прямые агенты)]].

## Порядок
0) `*<номер брони>` — открыть бронь (ШАГ 0). Полезно `*Р`.
1) Статусы купонов: `*С` и `ЭБ#<номер>` — возвращаются ТОЛЬКО неиспользованные (**O** — open). **C** (зарегистрирован) → сначала снятие с рейса; **F** (выполнен) → не возвращается.
2) Доп. услуги: `*ЭМД` — выпущенные ЕМД вернуть `ЭМДВВ#<N>` (вынужденный возврат ЕМД; используется и для багажа/места); только забронированные → снять `3У<N>"` / `34"`.
3) Правила тарифа: `ТМ/П` → `ТП1/16` — проверить условия возврата по УПТ.
4) Сумма к возврату: `ТМР/АПВ` — авторасчёт; сверять с правилами (система может посчитать штраф там, где по правилам его нет).
   ⚠️ Если рейс отменён/перенесён и в PNR осталась старая запись (статус UN) — `ТМР/АПВ` падает с ошибкой: считает маршрут вместе с отменённым рейсом. Тарифицируй ТОЛЬКО живой сегмент: `ТМР/АПВ*N` (или `ТМ/АПВ*N`), где N — номер строки нового рейса из `*Р`. Либо удали отменённый сегмент из записи.
5) (Аэрофлот, прямые агенты) ремарка основания в PNR, напр. `5H-DPM INVOL RFND DUE TO CANCEL/DELAY SUxxxx`; детальные основания «без авторизации» и шаблоны — в отдельной выжимке по возвратам Аэрофлота (в репозиторий не входит).
6) Возврат:
   - `АПВ` — всем пассажирам;
   - `АПВ<N>` — конкретному;
   - `АПВ*N` — по сегменту N (живой рейс при отменённом в PNR);
   - ручная маска `АПРД` — при отказе автоматики (частично использованный и т.п.).
   После ввода команды — ЛИСТАТЬ страницы стрелками (→) ДО КОНЦА: на финальном экране предупреждение «после этого действие будет невозможно отменить» — это и есть подтверждение возврата (шаг легко пропустить!).
   → `ЭМД/ПШ` (сборы/штраф, если есть) → `ЕО`.
7) Снять места: `ХМ` / `ХХ1` по участкам → `ЕО`. Запись не нужна → `И`.

## Аэрофлот — прямые агенты
Основания «без авторизации» (отмена/задержка >30 мин, медпричины по ФАП-82, овербукинг и др.), ремарка `5H-DPM INVOL RFND…`, сроки и отчётность SIRAX-Портал — вынесено в отдельный кейс: [[Аэрофлот — возвраты (прямые агенты)]].

## Пример: рейс перенесли — в PNR остался отменённый

> [!example] Ситуация (таск с доски 08.09)
> А/к U6 перенесла рейс с 11.09 на 14.09. В PNR два «хвоста»:
> - строка старого рейса — статус **УН2** (UN: рейс отменён, цифра = число пассажиров);
> - строка нового рейса — статус **ХХ2** (места сняты под возврат).
> Пассажиры подтвердили возврат в мобильном приложении а/к → расчёт можно не показывать, возвращаем сразу.

> [!warning] Загвоздка
> `ТМР/АПВ` (расчёт «на всё») → ошибка: система считает маршрут вместе с отменённым рейсом.

> [!success] Решение
> Считаем и возвращаем только живой сегмент — по номеру строки из `*Р`:
> 1. `ТМР/АПВ*2` — расчёт по сегменту 2;
> 2. `АПВ*2` — возврат сегмента 2;
> 3. листаем стрелками (→) до конца → «после этого действие будет невозможно отменить» → подтверждаем;
> 4. `ЕО`.
> (Альтернатива: удалить отменённый сегмент из записи и считать на всё.)

## Памятка
- Вынужденный возврат обычно без штрафа — но сверяй авторасчёт с `ТМ/П`/`ТП01/16`.
- Клиент «просто передумал» — это НЕ вынужденный возврат: это АПД (со штрафом).
- В PNR остался отменённый рейс (UN) → `ТМР/АПВ` падает: считай по живому сегменту `ТМР/АПВ*N`.
- После `АПВ` листай стрелками (→) до конца — финальное подтверждение «действие невозможно отменить».
- Уральские авиалинии (U6): доказательства причины вынужденного возврата/обмена отправляются на сайт U6 (ссылка — во внутренней документации). Вход: номер брони + номер билета БЕЗ первых 3 цифр (это код а/к). Причина + скриншоты (бронь до операции и `*ИМ` после).

## Порядок Миксвел (МКЛ) — сверка 21.09.2026

> [!info] Источник
> Инструкция кассира ГРС «Миксвел», ч. 2: гл. 5 «Возврат билетов (запрос `АП`)» и подглавы 5.6 «Вынужденный возврат», 5.7 «Псевдовозврат», 5.9 «Ручной возврат (запрос `АПР`)» (версия 05.06.26). Карта соответствий — [[Миксвел — расхождения с Сиреной и новые команды]].
> ⚠️ **На нашем пульте не проверялось.**

**Прямой порядок МКЛ (вынужденный возврат):**

1. `*<Номер_PNR>` — вызвать PNR.
2. `АПВ<ПАСС><*СЕГМ>` — вынужденный возврат. Инструкция даёт минимальный пример: `*(Номер_PNR)` → `АПВ` → `Е`.
3. Если вынужденный возврат **запрещён по УПТ** — сначала разрешить его основанием:
   `3С(СЕГМ)ПРОЧРВВП(свободный текст)`, где свободный текст = основание на разрешение вынужденного возврата (например, справка лечебного учреждения при болезни пассажира).
4. Если система не может рассчитать автоматически — реплика «СЛОЖНЫЕ УСЛОВИЯ. ИСПОЛЬЗУЙТЕ ЗАПРОС `АПР` ИЛИ `ПОР`» → `АПР<В>(ПАСС)*(СЕГМ)`, где `В` = вынужденный. Без буквы `В` считается, что возврат добровольный, и в маске высвечиваются данные для добровольного возврата.
5. `Е` — завершить диалог.

> [!warning] Расхождения и ограничения из МКЛ
> - **Запрет взимания сборов а/к при `АПР`:** «Установлен запрет на взимание сборов авиакомпании при возврате. При попытке ввода такого сбора… выходит сообщение „НЕВОЗМОЖНО ВЗЯТЬ СБОР ПРИ ВОЗВРАТЕ“». ⚠️ У нас в порядке (шаг 6) записано обратное — «в поля `АПРД` вписать сборы а/к и валюту». **Прямое противоречие, проверить на пульте.**
> - **`АПР` запрещена на сегменты прибытия.**
> - **Псевдовозврат `АПВ/-`** (гл. 5.7): «При этом сегмент из PNR не удаляется». Сбор перевозчика взимается по условиям вынужденного возврата (как правило, не взимается); если взимается — `ЭМД/ПШ/АП`; платы агентства выводятся на экран для оформления на бланке ЭМД — `ЭМД/ПК`; справка о возврате по желанию — `ЭМД/СП/ИСП`.
> - **Места.** В МКЛ возврат мест входит в саму операцию возврата; отдельная гл. 5.8 — возврат мест **без** финансового расчёта, запросом `ХХ(N)`. Правила: заблокирована сдача мест на использованные участки («НЕВОЗМОЖНО СДАТЬ МЕСТА НА 'ИСПОЛЬЗОВАННОМ' СЕГМЕНТЕ»); `ХХ` без номеров участков заблокирована («УТОЧНИТЕ НОМЕРА СЕГМЕНТОВ»); возврат на втором участке возможен только после использования первого.
> - **Возврат части пассажиров** — через деление PNR (`Д1` → `ЕО`), затем возврат места `ХХ2` → `Е`.
> - **Игнорирование после `АП`** отменяет возврат и **замораживает места**.
> - Перед процедурой `.md` инструкция требует прочитать УПТ (`ТМ/П` → `ТП(ВАР)`, для условий возврата `ТП(N)/16` или `/33`).

**Чего в нашем порядке нет:** `3С…ПРОЧРВВП` (разрешение вынужденного возврата при запрете по УПТ); псевдовозврат `АПВ/-`; «СЭБ <АК> ТРЕБУЕТ ОТДЕЛЬНОЙ ОПЕРАЦИИ НАД КАЖДЫМ ИЗ БИЛЕТОВ» → `АП1`, `АП2`; возврат начинать с **ребёнка без места**; активные бланки `СМ/ЭМД` и `СК/EMD` до подачи `АП`.
