# U6 — отмена рейса (кейс)

Ситуация: а/к Уральские авиалинии перенесла рейс (11.09 → 14.09). Пассажиры подтвердили возврат в мобильном приложении. Таск с доски 08.09.2026.

## Что было в PNR
- Старая запись рейса — статус **УН2** (UN: рейс отменён; цифра = число пассажиров).
- Новая запись (перенесённый рейс) — статус **ХХ2** (места сняты под возврат).

## Ход выполнения
1. Клиент подтвердил возврат в приложении а/к → по процедуре возврат делаем СРАЗУ, без показа расчёта.
2. `*С`, `ТМ/П` — по процедуре.
3. `ТМР/АПВ` → **ошибка**: система считает маршрут вместе с отменённым рейсом.

> [!warning] Загвоздка
> Расчёт «на всё» падает, если в PNR остался отменённый сегмент (UN). Нужно тарифицировать ТОЛЬКО живой сегмент — по номеру его строки из `*Р`.

4. `ТМР/АПВ*2` — расчёт по сегменту 2 (новый рейс).
5. `АПВ*2` — возврат сегмента 2.
6. **Листаем страницы стрелками (→) до конца** — на финальном экране «после этого действие будет невозможно отменить» → подтверждение.
7. `ЕО`.

Альтернатива вместо шага 4: удалить отменённый сегмент из записи и считать «на всё».

## Специфика U6: доказательства на сайт а/к
Для вынужденного возврата/обмена U6 нужно отправить подтверждения причины на сайт авиакомпании (ссылка — во внутренней документации, раздел U6):
1. Вход в запись пассажира: номер брони + номер билета **БЕЗ первых 3 цифр** (первые 3 цифры номера билета = код авиакомпании).
2. Выбрать причину (в кейсе — изменение расписания).
3. Прикрепить скриншоты: (1) брони в начале операции, (2) истории маршрута `*ИМ` после операции.
4. Отправить.
