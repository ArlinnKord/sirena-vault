# Обмен билета — команды

Быстрый скелет. Развёрнуто — [[Добровольный обмен]] и [[Вынужденный обмен]] (каждая команда расписана с подсказками). Ручной обмен — [[Ручной обмен (ПОР)]].

## Коды обмена — развилка
| Ситуация | Код |
|---|---|
| Автоматический обмен | `ПО` |
| Добровольный обмен (клиент меняет планы) | `ПОД` |
| Вынужденный обмен (по вине а/к) | `ПОВ` |
| Ручная маска (добровольный/вынужденный) | `ПОР*N` / `ПОРВ*N` |

## Скелет обмена
1. `*<номер брони>` — открыть бронь (ШАГ 0)
2. `ТМ/П` → `ТП1/16` — правила обмена (категория 16 УПТ)
3. `*Р` — текущее состояние сегментов
4. Наличие нового рейса: `1<ГГ><ГГ><ДДММ>-<АК>` → **`ОЦ#<N>`** — выбор рейса; открывается **список подклассов с ценами**, по нему выбираем подкласс. (Цену смотрим в двух окнах: в одном наличие/`ОЦ#1`, во втором — оценка рейса и, если цену забыли, тарификация текущей брони `ТМ`/`ТМР/ПО*N`.)
5. Забронировать НОВЫЙ сегмент **строкой выше** обмениваемого (`0<строка><класс>1`): при обмене нижняя (старая) строка **механически меняется на верхнюю** (новую) — поэтому новый рейс ВСЕГДА выше старого; старый снять `Х<N>`; одному пассажиру из нескольких — сплит `Д1`
6. `ЕО` — сохранить
7. Счёт: `ТМР/ПО*N` (или `ТМР/ПОД*N`/`ПОВ*N`) — сверять с правилами
8. `ЕО` — сумма зафиксирована
9. **ПОСЛЕ оплаты, непосредственно перед обменом** — пассивный сегмент (см. врез ниже): `0ПРИБ/N` → `ЕО` → сам обмен `ПО*N` (сегмент N; несколько участков на один — `ПО*1**2,3`)
10. `ЕО` → `ЭМД/ПШ` — сбор за обмен (если есть)

> [!info] Пассивный сегмент `0ПРИБ/N` — добавляется непосредственно ПЕРЕД обменом (шаг 9)
> `0ПРИБ/<N>` — **ПАССИВНЫЙ СЕГМЕНТ**: пустая строка-«заглушка», вставляемая в позицию N сегментов (N = место, куда вставляем; напр. `0ПРИБ/3`).
> **Когда:** НЕ при бронировании нового рейса, а сразу перед самим обменом: `0ПРИБ/N` → `ЕО` → `ПО*N`.
> **Зачем:** Сирена не проведёт обмен между рейсами с совпадающими пунктами вылета/прилёта — без пассивного сегмента не сохранит.
> В ОБЫЧНОЙ броне (не обмен) `0ПРИБ/2` — это просто порядок сегментов: рейс прибытия идёт вторым (см. [[Создание брони — команды]]).

> [!warning] Частые грабли
> - Обмен выполняется ТОЛЬКО после оплаты доплаты (шаг 9).
> - Вынужденный обмен: сбор за обмен обычно не берётся, место классом выше допустимо — но сверять авторасчёт с `ТМ/П`.
> - В PNR остался отменённый рейс — тарифицировать по живому сегменту `ТМР/ПО*N`.
> - Под звёздочкой всегда сегмент: `ПО*1`, не `ПО1*1`.
> - Повышение бренда при доплате: параметр `ПТ:БРЕНД=…` (см. [[Добровольный обмен]]).
