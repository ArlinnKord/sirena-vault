# Вынужденный обмен (по инициативе а/к: отмена/задержка, изм. расписания)

Код: **ПОВ** — вынужденный обмен (автоматический); **ПО**/ПОД — добровольный; ручная маска: **ПОРВ** (вынужденный) / ПОР (добровольный).

Быстрый скелет: [[Обмен билета — команды]]. Кейс: [[Аэрофлот — рерутинг]].

## Отличия от добровольного обмена
- Сбор за обмен (УПТ кат. 16) обычно НЕ взимается;
- доплата — только если пассажир сам выбрал более дорогой вариант/класс;
- допустимо дать место классом выше (нежелательно, но разрешено);
- авторасчёт сверять с `ТМ/П`/`ТП01/16` (система может посчитать штраф там, где его нет).

## Порядок
0) `*<номер брони>` — открыть бронь (ШАГ 0, в конспектах часто опускают). Полезно `*Р` — номера сегментов/пассажиры.
1) Статусы купонов: `ЭБ#<номер>` / `*С` — обмениваются ТОЛЬКО неиспользованные (**O**); **C** (зарегистрирован) → сначала снять с рейса; **F** (выполнен) → не обменивается.
2) Правила тарифа: `ТМ/П` → `ТП1/16`.
3) Наличие на новом рейсе: `1<ГГ><ГГ><ДДММ>-АК` (в GUI — «Подобрать новый рейс»).
4) Забронировать новый сегмент строкой ВЫШЕ обмениваемого (при обмене нижняя/старая строка **механически меняется на верхнюю**/новую — поэтому новый рейс ВСЕГДА выше); не всем пассажирам → сплит `Д1`; расставить `0М/…`; удалить старый `Х<N>` → `ЕО`.
5) Оценка/счёт: `ТМР/ПОВ*N` (расчёт без оформления) → `ЕО` (сумма зафиксирована).
6) После оплаты, **непосредственно перед обменом** — пассивный сегмент `0ПРИБ/N` (пустая строка-«заглушка» в позицию N; при обмене ВСЕГДА — иначе Сирена не сохранит между рейсами с совпадающими пунктами вылета/прилёта) → `ЕО` → сам обмен `ПОВ*N` → `ЕО`.
7) Автоматика не может (частично использованный билет / разные тарифы участков) → ручная маска `ПОРВ*N` (устройство маски — пособие «сирена пор.pdf»).
8) Нераспечатанные ЕМД на сборы: `ЭМД/ПШ` → завершение `Е`. Обменённый купон получает статус **E** (переоформлен), по FIM — **G**.

## Аэрофлот (рерутинг)
Сами переоформление НЕ выполняем: считаем доплату (разница тарифов + разница такс + сбор; при вынужденном по вине SU на тот же класс сбор и доплата не берутся) → счёт клиенту → при оплате письмо в а/к на переоформление (шаблон — во внутренней документации).

## Памятка
- Цифры после `ПОВ*` — номера сегментов из `*Р`, не пассажиры и не весь билет.
- Вынужденный ≠ «клиент передумал»: смена решения пассажиром — это добровольный обмен (ПО/ПОД) со сбором.
