# Ручной обмен (ПОР)

«Ручной» обмен — через маску с ручной коррекцией (билет печатает система автоматически). Автоматический обмен — команда `ПО`, ручной — `ПОР`. Разбор — по внутренней памятке по ПОР (в репозиторий не входит).

## Когда нужен ручной обмен (по 16-й категории УПТ)
- Частично использованный билет → нужно пересчитать тариф использованных участков.
- Обмениваемый участок тарифицируется по другому тарифу, но 10-я категория УПТ не предусматривает комбинирование.

## Формат
`ПОР<В><СЕГМ>*(ПАСС)` — В = вынужденный; нет В = добровольный. Пример: `ПОР*2` — ручной добровольный обмен сегмента 2.

## Этапы
1. Тарификация вновь забронированных участков (авто или `ТР`/`ВВ`, `ТВ`/`ВВ`, `ТО`).
2. Коррекция тарификации, переучёт стоимости обмениваемого билета и сборов — в маске.
3. Предварительная оценка: устроит → листать ВПЕРЁД; нет → `ИО` (отмена обмена).

> [!warning] Если реплика
> «НЕТ ВОЗМОЖНОСТИ АВТОМАТИЧЕСКИ ОЦЕНИТЬ МАРШРУТ НА ДАННЫХ БЛАНКАХ» — сначала провести ручную/полуавтоматическую тарификацию новых участков, потом `ПОР`.

## Устройство маски (поля)
- 1-я строка: операция `ОБМЕН`, тип `ДОБ/ВЫН`, номер PNR, ПАСС, СЕГМ.
- «ОБМЕНИВАЕМЫЙ БИЛЕТ» → «ВОЗВРАТ ТАРИФА +<код> +<сумма> +<валюта>» — практически меняют только сумму (величину тарифа, зачитываемого в новый билет).
- «НОВЫЙ БИЛЕТ» → новый тариф/сборы; «СБОР ЗА ОБМЕН» — при ручном обмене сумму сбора вписать самому.
- НББ — нормы бесплатного багажа: К (кол-во мест)/Ф (вес) — поля ввода, М — без изменений.

## История PNR после обмена (*И)
- Старый билет: `ТО` + `ПР` (переоформлен); новый: `ТО` + `ОД` (оформлен/др. операция).
- `КТ=<тариф>(х,у)` — новый тариф с указанием, что было: А/В/Р (добавлен/возвращён?) и МА/МР (для чего — уточнить).
- `ШТ=` — штраф, вписанный вручную. НББ(А/Р) — изменение нормы багажа.
- Ключи сборов `К=` в маске: ОВ/ВВ/ОТ/ПВ/ФВ/СД/СВ/ЭБ (в `*И` набор другой).
