# Добровольный обмен (клиент меняет дату/маршрут)

Код: **ПО** — обмен (автоматический), **ПОД** — явно добровольный обмен. Расчёт без оформления — `ТМР/ПО*N`. Тарификация обмена = выставление счёта.

Быстрый скелет: [[Обмен билета — команды]].

## Порядок
0) `*<номер брони>` → `*Р` — какие сегменты в PNR и их номера строк.
1) Правила тарифа: `ТМ/П` → `ТП1/16` — сбор за обмен, условия (УПТ кат. 16).
2) Наличие на новом рейсе: `1<ГГ><ГГ><ДДММ>-АК` (в GUI — кнопка «Подобрать новый рейс»).
3) Забронировать новый сегмент:
   - строкой ВЫШЕ обмениваемого (указать номер строки в PNR): при обмене нижняя (старая) строка **механически меняется на верхнюю** (новую) — поэтому новый рейс ВСЕГДА выше старого;
   - обмен не всем пассажирам → сплит `Д1`;
   - расставить `0М/…` (поменять местами); удалить старый сегмент `Х<N>` → `ЕО`.
4) Оценка (счёт): `ТМР/ПО*N` — предварительный расчёт без оформления; по пассажиру — `ТМР/ПО<N>*<M>`; смена бренда — `ТМ/ПО*N/ПТ:БРЕНД=<код>` → `ЕО`. Сохранение = сумма зафиксирована, счёт выставлен.
5) После оплаты счёта, **непосредственно перед обменом** — пассивный сегмент `0ПРИБ/N` (пустая строка-«заглушка» в позицию N; при обмене ВСЕГДА — иначе Сирена не сохранит между рейсами с совпадающими пунктами вылета/прилёта) → `ЕО` → сам обмен `ПО*N` → `ЕО`.
6) Нераспечатанные ЕМД на штрафы: `ЭМД/ПШ`.

## Состав счёта
Доплата по тарифу + разница такс (если новые больше) + сбор за обмен (УПТ кат. 16).

> [!example] Повышение класса обслуживания (эконом → бизнес)
> Отдельной команды «повысить класс» НЕТ. Такого пассажира **тарифицируем и проводим обмен** тем же порядком, что выше (наличие на новом рейсе в нужном классе → бронь нового сегмента → `ТМР/ПО*N` = счёт → после оплаты `ПО*N`). Подтверждено на пульте 10.09.2026.
> NB: подкласс (буква RBD `Э`/`U`/`Q`…) задаётся при бронировании — см. [[Создание брони на примере. (стыковка, разные подклассы)]]; смена статуса `0/1/НК` класс не меняет.

## Памятка
- Цифры после `ПО*`/`ТМР/ПО*` = номера СЕГМЕНТОВ из `*Р`, участвующих в обмене, — НЕ весь билет и НЕ пассажиры. Между обмениваемыми часто стоит сегмент, не участвующий в обмене. Ошибка в номерах → обмен не тех участков.
- `ТМ/ПО<N>*<M>`: цифра пассажира сразу после `ПО`, сегмент под `*`. НЕ писать `ТМ/ПО*1*1`.
- Авторасчёт сверять с `ТМ/П`/`ТП01/16` (система может посчитать штраф там, где по правилам его нет).
- Автоматика не может (частично использованный билет / 10-я категория УПТ не позволяет комбинировать) → ручной обмен маской `ПОР` (см. «сирена пор.pdf»).
