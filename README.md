# Сирена-Трэвел — конспекты по бронированию и оформлению

Готовые к чтению конспекты по работе в ГРС **«Сирена-Трэвел»**: команды пульта, создание брони,
тарифы, выписка билета, обмен, возврат, доп. услуги (ЕМД), корректировка данных. Каждая тема —
отдельная папка, внутри — короткая шпаргалка (скелет по шагам) и подробная заметка с пояснениями
и граблями. Точка входа — **`Сирена — навигация`**.

Формат — обычные заметки **Obsidian** (`.md` + вики-ссылки `[[…]]`). Поэтому «красиво» они
выглядят именно в Obsidian: работают переходы по ссылкам, раскрывающиеся блоки-врезки и поиск
по всему хранилищу.

---

## Как установить в свой vault (Obsidian)

Нужен установленный [Obsidian](https://obsidian.md) и какой-нибудь vault (можно пустой).
Дальше — любой из двух способов.

### Способ 1 — скачать ZIP (проще всего)

1. На странице репозитория нажмите зелёную кнопку **`Code` → `Download ZIP`**.
2. Распакуйте архив. Получится папка `sirena-vault-main` (или с именем ветки).
3. **Переименуйте её в `Сирена`** — так аккуратнее и совпадает с ссылками внутри заметок.
4. Положите папку `Сирена` внутрь своего vault — в любое место, но удобнее в корень:

   ```
   ВашVault/
   └── Сирена/
       ├── README.md
       ├── Сирена — навигация.md
       ├── 1. Создание брони/
       ├── 2. Возвраты/
       └── …
   ```

5. Откройте vault в Obsidian. Слева в списке файлов появится папка `Сирена`.

### Способ 2 — через git (если хотите обновлять конспекты)

В терминале перейдите в папку своего vault и клонируйте репозиторий прямо внутрь:

```bash
cd "путь/к/вашему/vault"
git clone https://github.com/ArlinnKord/sirena-vault.git Сирена
```

Обновление до свежей версии — `git pull` внутри папки `Сирена`.

### Проверка настроек Obsidian

Чтобы вики-ссылки и картинки отображались как надо, в Obsidian:
**Настройки → Файлы и ссылки → «Использовать Wikilinks»** должно быть **включено** (по умолчанию
включено). Этого достаточно — специально настраивать ничего не нужно.

### С чего начать чтение

Откройте **`Сирена — навигация`** — это карта знаний: выбираете операцию и переходите в нужную
папку. В конце каждой заметки есть блок **«Связано»** со ссылками на смежные темы.

## Структура

| Папка | О чём |
|---|---|
| `1. Создание брони` | Создание PNR, ФИО/документы, контакты, тайм-лимит, тарификация, выписка + примеры с доски |
| `2. Возвраты` | Добровольный (АПД) и вынужденный (АПВ) возврат, спецслучаи (U6, Аэрофлот) |
| `3. Обмен билета` | Добровольный (ПО/ПОД), вынужденный (ПОВ), ручной обмен (ПОР), спецслучаи |
| `4. Доп. услуги (ЕМД)` | Оформление и тарификация доп. услуг: место, багаж, питание |
| `5. Справочники` | Команды пульта, коды и статусы, мнемоника сохранения, таксы по сегментам |
| `6. Корректировка данных` | Смена ФИО/паспорта в выписанном билете, коды документов |
| `_Архив черновиков` | Черновые заметки (в работе не нужны, оставлены для истории) |

Точка входа — `Сирена — навигация.md` в корне.

## Источники

Конспекты собраны по первоисточникам: инструкциям ГРС «Сирена-Трэвел» и «Миксвел», внутренним
памяткам авиакомпаний и записям с пульта.

Тексты самих методичек (полные инструкции вендоров) **в этот репозиторий не входят** — они
хранятся отдельно и не публикуются. Ссылки вида «Миксвел, ч. 2, с. 213» указывают на раздел
инструкции, а не на файл в репозитории.
