# Корректировка данных — команды

Смена данных в ВЫПИСАННОМ билете: ФИО, дата рождения, пол, паспорт. Проводится как операция обмена **без изменения полётного сегмента** — через `БЛД`; если БЛД не работает — через `УСЛТ` + ЕМД.

> [!info] Источники
> «Профи команды» + запись с пульта 10.09.2026 + инструкция кассира ГРС «Миксвел», ч. 2, разд. 8.5.12 «Обмен билета без изменения полётного сегмента (запрос БЛД/БЛВ)», с. 213. ЕМД и УСЛТ — [[ЕМД — операции и коды]].

> [!warning] Два порядка в источниках
> - **«Профи команды» + Миксвел 8.5.12:** сначала правим данные и сохраняем (`-1"…`/`ДД1/…` → `ЕО`), затем `БЛД1` (сбор считает сам обмен). Это независимое подтверждение из двух мест.
> - **Запись 10.09.2026 (пульт):** `ТМ/БЛД1` (расчёт/счёт) → оплата → правка данных → `БЛД1`.
> - Основной берём **«правка → БЛД»**; запись 10.09 — как вариант порядка с пульта (см. ниже). Итог проверить на практике.

## Основной путь (БЛД работает)

0. Открыть бронь: `*<номер PNR>`.
1. `ТМ/П` → `ТП1/16` — прочитать правила тарифа: разрешена ли смена данных и какой сбор.
2. Внести изменение → `ЕО`:
   - ФИО / дата рождения / пол — `-1"<ФИО ДАТАРОЖ+ПОЛ>` (напр. `-1"KRASOVSKAYA KRISTINA 010593+Ж`);
   - **паспортные данные — НЕ через `-1`, а `ДД1/<номер>`** (напр. `ДД1/4522133200`).
   - Если сохранить не удалось: реплика «СОХРАНИТЕ ИЛИ ОТМЕНИТЕ ИЗМЕНЕНИЯ ИМЕНИ (ЕО/ИО/И)».
3. `ТМ/БЛД1` — расчёт/выставление счёта (1 — номер пассажира). `ТМР/БЛД1` — тот же запрос, только вид расчёта на экране другой (см. «Ключевое»); для клиента — отправить расчёт.
4. `БЛД1` → `ЕО` — исполнение корректировки (после оплаты счёта).
5. `ЭМД/ПШ` — печать сборов/штрафа (если есть нераспечатанные ЕМД). ✅ Подтверждено «Профи команды»: «Если есть нераспечатанные эмд на штрафы – ЭМД/ПШ»; та же команда на возвратах и обмене.

> [!info] Подтверждение из Миксвела
> Инструкция кассира Миксвел, ч. 1 (с. 263): при изменении в PNR с выписанным билетом номера документа и/или категории пассажира при закрытии выдаётся реплика «ПЕРЕОФОРМИТЕ БИЛЕТ ДЛЯ ПАССАЖИРА С ИЗМЕНЕННЫМИ ДАННЫМИ» → переоформление **запросом `БЛД`/`БЛВ`**.

## Порядок из записи 10.09 (пульт, требует подтверждения)

0. `*<номер PNR>` — открыть бронь.
1. `ТМ/П` → `ТП1/16` — правила (разрешена ли смена данных, какой сбор).
3. `ТМ/БЛД1` — расчёт/счёт (нумерация источника 0, 1, 3, … — шаг 2 пропущен).
   - **Первичное задание от клиента** — отправляем расчёт и закрываем бронь (данные не меняем).
   - **Услуга уже оплачена** — идём дальше.
4. Внести изменение (`-1"…` / `ДД1/…`) → `ЕО`.
5. `БЛД1` → `ЕО` — исполнение после оплаты.
6. `ЭМД/ПШ` — печать сборов/штрафа.

> [!note] Чем отличается от основного пути
> Здесь **счёт (`ТМ/БЛД1`) стоит ДО правки данных**. Возможное согласование: в разговоре с клиентом сначала выставляют счёт, а сама правка и `БЛД1` физически идут после оплаты. Что первично на пульте — проверить на практике.

## Если БЛД не работает

1. Если в `ТП1/16` **нет правил корректировки данных** → читаем правила оформления через `ИА/<АК>/<разделы>` — справочник перевозчика. Подтверждённый аналог: `ИА/ЮТ/4/2/6` («Технология оформления размещена в справочнике Перевозчика»). Точные номера разделов — во внутренней документации а/к.
2. Ищем услугу «корректировка данных» через `УСЛТ`: `УСЛТ*` — список доступных услуг; `УСЛТ<N>*<M>` — для N-го пассажира на M-м сегменте (напр. `УСЛТ2*1`).
3. Далее — как при оформлении ЕМД (см. [[ЕМД — операции и коды]]):
   - `3УАС<сегм>П<пасс>А1//<код>` — добавить услугу с кодом из УСЛТ → `ЕО`;
   - внести изменение (`-1"…` / `ДД1/…`) → `ЕО`;
   - тарификация `ТМ/<буква>+У<N>` (букву **всегда копировать из УСЛТ**; напр. `ТМ/М+У2`) → выпуск `ЭМДА/<буква>+У<N>`.

## Ключевое

- **`-1"…` — ФИО/дата/пол; `ДД1/…` — паспорт/документ.** Паспорт через `-1` не менять.
- **`ТМР/БЛД1` = `ТМ/БЛД1`** — одно и то же. `ТМ` и `ТМР` отличаются ТОЛЬКО видом расчёта на экране: с «Р» — ручной, таксы расписаны подробнее.
- `БЛД1` — исполнение переоформления билета (перевыпуск, после оплаты счёта). `БЛРД1` — то же «вручную» через маску (`БЛ`-`Р`-`Д` = ручной + добровольный перевыпуск).
- Сбор за изменение данных (из правил тарифа): внутри РФ — 1000 ₽; за границу (пример — Казахстан) — 15 €. Конвертация: `ПВ/15/ЕВР/РУБ`.

> [!warning] `БЛД` — это ПЕРЕВЫПУСК (переоформление) билета, а не «изменение данных»
> Последняя буква = вид переоформления: **`Д` = Добровольный · `В` = Вынужденный** (как в `АПД`/`АПВ`, `ПОД`/`ПОВ`), а НЕ «данные».
> - `БЛД<N>` — **добровольное** переоформление (перевыпуск) билета без изменения полётного сегмента; `N` — номер пассажира.
> - `БЛВ<N>` — **вынужденное** переоформление.
> - `БЛРД<N>` / `БЛРВ<N>` — то же, но «вручную» через маску (`Р` = ручной).
> - `БЛ<N>` (нативный формат Сирены) — обмен билета при изменении поля имени пассажира; маска — `БЛР<N>`.
> «Данные о пассажире» в формулировке Миксвела — это *предмет* обмена (что меняем), а не расшифровка буквы `Д`.

## Открытые вопросы / расхождения

- **Порядок шагов.** «Профи команды» и Миксвел 8.5.12 — правка ДО `БЛД` (сбор считает сам обмен). Запись 10.09 — счёт (`ТМ/БЛД1`) ДО правки. Что первично на пульте — проверить на практике, сверив с Миксвел 8.5.12.
- **~~`БЛРД1`~~** — снято: `БЛРД1` = ручное добровольное переоформление (перевыпуск) билета через маску; «перепечатать билет» в источнике и «ручная маска» в памяти — об одном и том же.
- **`БЛ` = «автовыбор» между `БЛД`/`БЛВ`?** Рабочая гипотеза (по аналогии с `АП` → `АПД`/`АПВ`, `ПО` → `ПОД`/`ПОВ` — по нашей практике, 04.10.2026). Прямо в источнике не сформулировано: нативная Сирена описывает `БЛ1` просто как «обмен билета при изменении поля имени». Проверить на практике.
- **`ТП/М+У2`** из записи — вероятно опечатка; подтверждённый формат `ТМ/<Ф|М|Р|С>+У<N>` (буква из УСЛТ).
- **`ИА/НН`** и конкретный `ИА/U6/32/1/1` — формат разделов подтверждён аналогом `ИА/ЮТ/4/2/6`, номера под U6 не проверены.
- В исходной записи **пропущен шаг 2** (нумерация 0, 1, 3, 4, 5, 6) — содержание шага 2 неизвестно.
