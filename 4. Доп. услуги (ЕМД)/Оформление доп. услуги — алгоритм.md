# Оформление доп. услуги — алгоритм

Общий путь: услуга бронируется как СВС-элемент в блоке 3 → тарифицируется → оформляется ЕМД. Номера СВС-элементов — У1, У2… (видно после `ЕО`/`*С`).

## Алгоритм
1. Услуга бронируется строкой блока 3 — ДВА формата (09.09.2026):
   - **Стандартная услуга с кодом** каталога (УСЛТ): `3УАС1П1А1//0CZ` — после `//` код продукта (0CZ, 0AR, 0ED…), без свободного текста;
   - **Услуга со свободным описанием**: `3УАС1П1SPEQ 10КГ 20X45X60` / `3УАС1П1PETC CAT 8КГ` — алфавитный токен сразу после П1 (БЕЗ `//`), после ПРОБЕЛА свободный текст: вид и параметры (животное — `CAT 8КГ`, спорт. инвентарь — вес+габариты). `//` = услуга с кодом; пробел после токена = свободное описание.
   - Место в салоне: `КМС1` (карта мест сегмента 1) → `3С1П1НМСТ05D` (блок 3/сегм./пасс./НМСТ/место)
2. `ЕО` (сохранить) или `ИО` (игнорировать, оставаясь в брони) — чтобы появился СВС-элемент.
3. `УСЛТ` — список услуг: взять номер Уn и **букву вида услуги** (Ф/Р/С/М — см. [[ЕМД — операции и коды]]).
4. `ТМР/<буква>+У1` — расчёт стоимости (на неё выставляется счёт).
5. После оплаты — выпуск: `ЭМДА/<буква>+У1` (по нескольким: `ЭМДА/<буква>+У1-2`).
6. Удаление лишней/неверной услуги: `3У1"` (3 — блок, У1 — услуга, `"` — удалить).

> [!warning] Грабли
> - Код вида услуги (`Ф`/`Р`/`С`/`М`) НЕ всегда по смыслу (был случай: питание = Ф) — ВСЕГДА копировать букву из `УСЛТ`/`*С`, не угадывать.
> - Статус СВС-элемента для оформления не должен быть UN или XX.
> - СВС-запись в брони может быть неправильной/устаревшей — правильное смотреть в `УСЛТ` и в расчёте `ТМР/<буква>+Уn`, не доверять строке блока 3 слепо (доска 09.09.2026, подтвердить).
> - Спорт.инвентарь/экзотика — не базовые услуги: у каждой а/к свои правила, сверять.
