# Оформление доп. услуги (примеры)

Два прогона одного таска с доски:
1. код услуги `0GO` — посмотрели **цену** (`ТМР`) и выставили клиенту счёт, до выпуска ЕМД не дошли → в конце `И`;
2. **багаж**, код `0CZ` — забронировали → `ТМР/Р+У1` → выпустили ЕМД (`ЭМДА/Р+У1:…@MAIL.RU`) → потом удалили услугу (`3У1"`).

## Порядок
0) `*<номер брони>` — открыть бронь (ШАГ 0, в конспектах часто опускают).
1) `УСЛТ` — список доступных услуг. Под «звёздочкой» — номер сегмента и пассажира (формат из инструкции: `УСЛТ2*1` = доступные услуги для 2-го пассажира на 1-м сегменте; «нет модификации по коду»).
   В списке — коды услуг, напр. `0GO`/`0CZ` и `Р/С`:
   - `0GO`/`0CZ` — код конкретной услуги → для бронирования (шаг 2);
   - `Р/С` — код вида услуги → для тарификации (шаг 3): берётся **Р или С**.
   ⚠️ Коды НЕ всегда следуют смыслу услуги (подтверждено на пульте 07.09: у питания в примере был код Ф, а не С). ВСЕГДА смотреть код у конкретной услуги в `УСЛТ`/`*С` и КОПИРОВАТЬ его в тарификацию, не угадывать по смыслу.
2) `3УАС1П1А1//<код>` + `ЕО` + `ИО` — бронирование услуги (формирование СВС-элемента): формат `3УАС1П1А1//<код>` (пассажир 1, сегмент 1), `//0GO`/`//0CZ` — код из шага 1.
   `ЕО` — сохранить; `ИО` — игнорировать, оставаясь в брони, чтобы обновился статус СВС-элемента.
   ⚠️ Статус СВС-элемента для оформления не должен быть UN или XX.
3) `ТМР/<Р|С>+У1` — предварительная тарификация услуги: **Р** — вид услуги, взятый из кода `Р/С` шага 1 (для багажа — Р; если С — пишем `ТМР/С+У1`); **У1** — номер строки СВС-элемента.
   Здесь смотрим стоимость услуги → на эту сумму выставляем счёт клиенту.
4) Дальше по задаче:
   - только счёт/цена (пример `0GO`): в конце — `И`, выходим;
   - выпуск ЕМД (пример `0CZ`, багаж): `ЭМДА/Р+У1` — оформление; с отправкой на почту: `ЭМДА/Р+У1:JULKAM94@MAIL.RU`.

## Удаление услуги: 3У1"
`3У1"` — удалить услугу 1. Разбор:
- `3` — номер блока на экране брони, где лежат доп. услуги;
- `У1` — услуга №1 (СВС-элемент);
- `"` (кавычка) — «удалить/стереть» строку.
У брони есть блоки с номерами: `3` — доп. услуги/ССР, `5` — примечания, `9` — контакты и др. (номера блоков запомнить/«выучить потом»). Общее правило удаления строки: `<номер блока><что удалить>"` (напр. `51"` — примечание, `91"` — контакт).
В блоке 3 бывают не только услуги (`3У1"`), но и записи-ремарки об ЕМД — они удаляются по номеру в списке: `32"` = удалить 2-ю запись (ремарку об ЕМД, которое уже вернули/войдили). Вторая цифра — номер записи в списке блока.

## Дальше (если бы оформляли дальше, из «Оформление емд.odt»)
- `ЭМДА/С+У2` — выпуск ЕМД на услугу (У2 — номер СВС-элемента); с почтой — `ЭМДА/С+У2::test@test.ru` или с одним двоеточием — оба работают, «ставь как работает» (09.09.2026).
- Автоматическая тарификация (не предварительная): `ТМ/С+У2`.
