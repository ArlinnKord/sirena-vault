# ЕМД — операции и коды

ЕМД (электронный многоцелевой документ) — квитанция на доп. услуги: место, багаж, питание и пр. Список ЕМД брони — `*ЭМД` (не `ТМ/ЭМД`!).

## Операции с ЕМД
- `ЭМДА/<буква>+Уn` — выпуск ЕМД на услугу (по нескольким: `ЭМДА/Ф+У1-2`)
- `ТМ/АП+Уn` — **расчёт услуги перед возвратом** (тарификация возврата, сумма со знаком минус)
- `ЭМДО#N` — войд ЕМД (аннуляция)
- `ЭМДВ#N` — возврат ЕМД (N — номер из списка `*ЭМД`); `ЭМДВ+Уn` — возврат по номеру СВС-элемента
- `ЭМДВВ#N` — вынужденный возврат ЕМД
- `ЭМДМВ+У2+У1` — обмен ЕМД
- `ЭМДК#N` / `ЭМДК/почта` — отправить квитанцию
- `ЭМД/ПШ` — квитанция сборов/штрафа (при возврате/обмене билета)

> [!warning] Статус СВС-элемента перед оформлением
> Услуга для оформления должна иметь подтверждённый статус. **`УН` (UN) = не засчиталась** (10.09.2026: при повторном бронировании места запись появляется, но со статусом УН — силы не имеет) → перебронировать; `XX` — места сняты. Смотреть статус строки, а не факт её появления.

> [!success] Расчёт услуги перед возвратом — `ТМ/АП+Уn`
> Перед возвратом ЕМД **желательно проверить тарификацию возврата**: `ТМ/АП+Уn` (сумма к возврату идёт со знаком минус). Подтверждено 01.10.2026 + Миксвел ч. 2, гл. 8.5.9 (с. 168). Отдельная заметка → [[Тарификация доп. услуги — команды]].

## Где выписан ЕМД — сверка по ППР
- `ЭМД#<номер>` — открыть ЕМД по номеру (вне брони).
- Если неясно, где были выписаны доп. услуги: взять их номера → открыть Сирену → в **двух параллельных окнах** открыть `ЭМД#<номер>` по каждому → сравнить код `ППР` (пункт продажи). **Разные ППР = разные пункты продажи:** одно выписали мы, другое — а/к.
- Так же работает **в графических пультах** (Победа, Аэрофлот и др.) — смотреть ЕМД по номерам.
- ⛔ **Не входить в саму бронь** через Сирену из графического пульта — запрещено. Только просмотр ЕМД по номеру.

## Буквы вида услуги (в `ТМ/<буква>+Уn` и `ЭМДА/<буква>+Уn`)
- `Ф` — место в салоне
- `Р` — багаж
- `С` — сервис/услуга (питание и пр.)
- `М` — изменение (ФИО и т.п.)

> [!warning] ⚠️ Коды НЕ всегда по смыслу
> Встречался случай, когда у питания был код `Ф`. Всегда копировать букву из `УСЛТ`/`*С`, где вид услуги указан рядом с номером Уn.

## Списки услуг (УСЛТ)
- `УСЛТ` — список услуг в брони; `УСЛТ2*1` — по пассажиру/сегменту.
- Оттуда берутся: код продукта (0CZ, 0AR, 0ED…), буква вида услуги, номер СВС-элемента Уn.
- Бронь услуги из УСЛТ: `3УАС1П1А1//<код>`.
