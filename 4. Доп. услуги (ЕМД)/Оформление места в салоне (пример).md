# Оформление доп. услуги — выбор места в салоне (пример)

Пример: добавить услугу «выбор места». Место в примере — **17F**.

## Порядок
0) `*<номер брони>` — открыть бронь (ШАГ 0, в конспектах часто опускают). Полезно `*Р`.
1) `КМС1` — карта мест на 1-м сегменте (`КМС<N>` — по номеру сегмента). Длинный запрос карты: `КМ2*Y`.
2) `3С1П1НМСТ17F` — забронировать место 17F: `3` — блок доп. услуг; `С1` — сегмент 1; `П1` — пассажир 1; `НМСТ` — тип строки «номер места»; `17F` — место. После бронирования: `ЕО` (сохранить) + `ИО` (игнорировать, оставаясь в брони, чтобы появился/обновился СВС-элемент). ⚠️ Проверить **СТАТУС** СВС-элемента (не только факт появления строки): **УН (UN) = услуга НЕ засчиталась → перебронировать** (10.09.2026: при повторном бронировании места запись появляется, но со статусом УН — силы не имеет); `XX` — места сняты. К оформлению годна только подтверждённая строка.
3) `ТМР/Ф+У1` — предварительная тарификация услуги: **Ф** — вид услуги «место» (взятый из кода услуги, см. правило ниже), **У1** — номер строки СВС-элемента. Здесь видна цена места.
4) Дальше — разветвление по задаче:
   - **расчёт/счёт** (как на доске): цену посмотрели → выставляем счёт клиенту → в конце `И`, выходим (ЕМД не выпускаем);
   - **выписка (ЕМД)**: `ЭМДА/Ф+У1` — выпуск ЕМД на место (с почтой — одно или два двоеточия перед адресом — неважно, оба работают, 09.09.2026: `ЭМДА/Ф+У1:test@test.ru`);
   - **удаление**: `3<N>"` — убрать место (N — номер строки в блоке 3; в примерах из памятки — `34"`). После удаления — `ЕО`/`И` по ситуации.

## Памятка
- Коды услуг НЕ всегда следуют смыслу (подтверждено на пульте 07.09: у питания был код Ф). Для места типовой код — Ф, но ВСЕГДА проверять код у конкретной услуги (`*С`/`УСЛТ`) и копировать его в `ТМ/<буква>+Уn` / `ЭМДА/<буква>+Уn`.
- Не путать: здесь выбирается КРЕСЛО (услуга: `КМС1`/`НМСТ`, оформляется ЕМД). Класс бронирования рейса (буквы U/Q/Э/П при бронировании, напр. `01UQ1`) — другое: это ценовая категория билета, см. [[Создание брони на примере. (стыковка, разные подклассы)]].
- `ТМР/…` — предварительный расчёт (не оформляет); `ТМ/…` — автоматическая тарификация; `ЭМДА/…` — выпуск ЕМД.

> [!info] Карта мест — только салон своего подкласса
> `КМС1` открывает лишь ту часть ВС, где есть места забронированного подкласса: бронь в экономе — бизнес-салона на карте не будет (и наоборот). Выбор кресла ограничен своим салоном. (Выяснено 10.09.2026.)
> Ещё раз про термины: **НМСТ** — это КРЕСЛО (услуга, оформляется ЕМД); буква класса при бронировании (`Э`, `U`, `Q`…) — это подкласс/ценовая категория билета (RBD), к креслу отношения не имеет.
