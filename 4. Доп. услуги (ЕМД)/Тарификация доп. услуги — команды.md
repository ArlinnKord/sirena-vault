# Тарификация доп. услуги — команды

Тарификация доп. услуги (`ТМ/<буква>+Уn`, `ТМР/<буква>+Уn`) и расчёт услуги перед её возвратом.

## Документированные команды
| Команда | Что делает | Источник |
|---|---|---|
| `ТМ/<буква>+Уn` | **тарификация услуги** (полная/автоматическая) | «Оформление емд» (`ТМ/Ф+У2`, `ТМ/С+У2`) |
| `ТМ/Ф+У1`, `ТМ/Ф+У1-2` | расчёт по месту (одно / несколько) | «Профи команды» |
| `ТМ/Ф(Р)+У1` | тарификация багажа | «Профи команды» |
| `ТМ/М+У5` | Победа, корректировка ФИО | «Профи команды» |
| `ТМР/<буква>+Уn` | **предварительная** тарификация (цена → счёт) | практика с доски |
| `ТМ/С+У2+У1` | проверка возможности ПЕРЕОФОРМЛЕНИЯ (новая + старая) | «Оформление емд» |
| **`ТМ/АП+Уn`** | **расчёт услуги перед её ВОЗВРАТОМ** | Миксвел ч. 2, гл. 8.5.9 (с. 168) |

Буквы вида услуги: **Ф** — место · **Р** — багаж · **С** — сервис (питание и пр.) · **М** — изменение. ⚠️ Буква НЕ всегда по смыслу — копировать из `УСЛТ`/`*С` рядом с номером Уn. См. [[ЕМД — операции и коды]].

## Расчёт услуги перед возвратом — `ТМ/АП+Уn` ✅ подтверждено

Команда **существует и правильна**. Подтверждено на пульте 01.10.2026 + первоисточником: Инструкция кассира ГРС «Миксвел», ч. 2, гл. 8.5.9 «Возврат ЭМД», с. 168 (версия 05.06.26).

Дословно из инструкции:
> 8. Произвести возврат ЭМД.
> Перед возвратом ЭМД желательно проверить тарификацию
> `ТМ/АП+У1`

Результат — обычный тарифный экран, но сумма к возврату идёт со знаком **минус** (в примере `ИТОГО -850.00 РУБ`). То есть `ТМ/АП+Уn` — это тарификация ВОЗВРАТА услуги: показывает, сколько вернётся по ЕМД №Уn.

### Сам возврат — по номеру ЭМД или по СВС-элементу
Из той же главы:
> Возврат ЭМД можно произвести как по номеру ЭМД, так и по номеру из предварительно вызванного списка ЭМД и по номеру СВС элемента.
> Произвести возврат ЭМД по номеру СВС элемента в PNR:
> `ЭМДВ+У1`

- `ЭМДВ+Уn` — возврат по номеру СВС-элемента (из PNR);
- `ЭМДВ#N` — возврат по номеру из списка `*ЭМД`.

После операции система показывает экран «ВОЗВРАТ … ДОБР ТАРИФ 850.00РУБ(850.00РУБ)» и предупреждение **«ОПЕРАЦИЯ ВОЗВРАТА ЭМД НЕОБРАТИМА. ОТМЕНИТЕ ОПЕРАЦИЮ (ИО/И) ИЛИ ЛИСТАЙТЕ ВПЕРЕД»** → листать «ВПЕРЁД» → `И` (конец диалога).

> [!warning] Срок
> Если ЭМД не вернуть в отведённый период (в примере — 3 дня), он остаётся оформленным и **вернуть его уже нельзя**.

### Про запись «ТМП/АП+У1»
Команды `ТМП` в Сирене нет. Запись `ТМП/АП+У1` — искажение правильной **`ТМ/АП+У1`** (вероятно, склейка с `ТМ/П` — правила тарифа). Подсказанная коллегой команда была верной по сути, ошибка была только в записи.
